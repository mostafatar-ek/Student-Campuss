# Student-Campuss

This repository contains the Student Portal Spring Boot application.

Quick start
1. Install Java 17 (or the version specified in `pom.xml`) and Maven.
2. From the project root run the student portal module:

```bash
cd student-portal
mvn spring-boot:run
```

Project layout
- `student-portal/` — Spring Boot application (main module)

Notes
- Database file `student-portal/data/studentportal.mv.db` is included for local testing.
